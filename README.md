# ICU Handover Dashboard

แบบส่งเวรผู้ป่วยวิกฤต (ICU Handover Checklist) แบบดิจิทัล: FANCAS · FASTHUGBID · DOPE · แผนการดูแลต่อเนื่อง
เป็นไฟล์ HTML / CSS / JS ล้วน (ไม่ต้อง build) ติดตั้งบน iPhone / iPad / Android ได้ (PWA)

> **ข้อมูลกลางของวอร์ด**: ทุกเครื่องที่เข้าระบบด้วยรหัสวอร์ดเห็นข้อมูลชุดเดียวกัน (Supabase, เซิร์ฟเวอร์สิงคโปร์)
> ใช้ชื่อย่อ + เตียง ใส่ข้อมูลเท่าที่จำเป็น · ระบบช่วยบันทึกและตรวจความครบถ้วนเท่านั้น ไม่สร้างคำแนะนำการรักษา

## ข้อมูลกลาง (Supabase)
* เข้าระบบด้วย **รหัสวอร์ด** ครั้งเดียว เครื่องจำไว้ · ใส่ "ชื่อของคุณ" ไว้แสดงในประวัติการแก้ไข
* ซิงก์อัตโนมัติทุก 15 วินาที (และทุกครั้งที่เปิดแอป / มีเน็ตกลับมา) · ป้ายมุมขวาบนบอกสถานะ (ซิงก์แล้ว / รอส่ง / ออฟไลน์)
* เน็ตหลุด: ใช้ต่อได้ การแก้ไขจะรอส่งเมื่อมีเน็ต
* แก้บันทึกเดียวกันพร้อมกัน: รวมการแก้ไขตามหมวด (FANCAS / FASTHUGBID / DOPE / แผน ...) ถ้าอีกเครื่องส่งเวรไปแล้ว บันทึกจะล็อก
* สิทธิ์คุมที่ฐานข้อมูล (Row Level Security): ไม่ login = มองไม่เห็นข้อมูล · ปิดการสมัครเอง · ลบได้เฉพาะฉบับร่าง · บันทึกที่ส่งเวรแล้วแก้ไม่ได้
* ตั้งค่าฐานข้อมูล: `../supabase/setup.sql` (รันครั้งเดียวใน SQL Editor) · ค่า `ICU.CLOUD` อยู่ใน `config.js`
* รหัสวอร์ดที่พิมพ์ (ตัวพิมพ์เล็ก/ใหญ่ได้) จะถูกแปลงเป็นตัวพิมพ์ใหญ่ + `passSuffix` ใน `config.js` (Supabase ต้องการรหัส ≥ 6 ตัว)
  เช่น พิมพ์ `SUTH` → รหัสจริงของบัญชี = `SUTH-icu-ward`
* เปลี่ยนรหัสวอร์ด: Supabase → Authentication → Users → บัญชีวอร์ด → Update password = `<รหัสใหม่ตัวพิมพ์ใหญ่>-icu-ward`
* อัปเดตฐานข้อมูล 26 ต.ค. (ถังขยะ / ลบถาวร): รัน `../supabase/update-2026-10-26.sql` ครั้งเดียว

## ขึ้น GitHub Pages + ติดตั้งบนมือถือ
1. repository บน github.com (Public) → **Add file → Upload files**
2. ลาก **ไฟล์ที่แก้** จากโฟลเดอร์นี้ (ไม่มีโฟลเดอร์ย่อย) ไปวาง → Commit (ไฟล์ชื่อเดิมจะถูกแทนที่)
3. **Settings → Pages** → Branch `main` / `/ (root)` → Save → `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`
* iPhone / iPad (Safari): ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** · Android (Chrome): เมนู ⋮ → **ติดตั้งแอป**

แก้ไฟล์แล้วอัปโหลดใหม่: เปลี่ยน `VERSION` ใน `sw.js` ด้วย (มือถือจะได้เวอร์ชันใหม่)

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `config.js` | หัวข้อ / รายการในแบบฟอร์ม, สถานะ, ค่าเชื่อมต่อ Supabase |
| `store.js` | สำเนาข้อมูลในเครื่อง + Audit log + บันทึกว่าอะไรยังไม่ได้ส่ง |
| `cloud.js` | เข้าระบบ, ส่ง / ดึงข้อมูลกับ Supabase, รวมการแก้ไขที่ชนกัน, ออฟไลน์ |
| `validate.js` | ตรวจความครบถ้วน + ข้อความสรุป |
| `editor.js` | หน้าบันทึกส่งเวร 5 ขั้น |
| `print.js` | แบบฟอร์ม A4 |
| `app.js` | เมนู, หน้าหลัก, ผู้ป่วย, ประวัติ, ตั้งค่า |
