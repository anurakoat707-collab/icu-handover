# ICU Handover Dashboard

แบบส่งเวรผู้ป่วยวิกฤต (ICU Handover Checklist) แบบดิจิทัล: FANCAS · FASTHUGBID · DOPE · แผนการดูแลต่อเนื่อง
เป็นไฟล์ HTML / CSS / JS ล้วน ไม่มี server ใช้แบบออฟไลน์ได้ และติดตั้งบน iPhone / iPad / Android ได้ (PWA)

> ข้อมูลผู้ป่วยเก็บใน `localStorage` ของเครื่องที่เปิดใช้เท่านั้น ไม่ถูกส่งไปที่ไหน (GitHub เก็บแค่ตัวเว็บ)
> ไม่มีระบบเข้าสู่ระบบ (แนะนำให้ตั้งรหัสล็อกมือถือ) · ระบบช่วยบันทึกและตรวจความครบถ้วนเท่านั้น ไม่สร้างคำแนะนำการรักษา

## เมนู
| เมนู | ทำอะไรได้ |
|---|---|
| **หน้าหลัก** | เลือกวันที่ / เวร (ดึก เช้า บ่าย) · สรุปจำนวน ยังไม่เริ่ม / Draft / Ready for Review / ส่งเวรแล้ว · การ์ดผู้ป่วยพร้อมความคืบหน้าแต่ละหมวด |
| **จัดการผู้ป่วย** | ค้นหา HN / AN / ชื่อ · กรองสถานะ / เวร / ห้อง · เพิ่ม / แก้ไข / เก็บถาวร (ไม่ลบจริง) · รายละเอียด + บันทึกล่าสุด + ประวัติ |
| **บันทึกส่งเวร** | 5 ขั้น: FANCAS → FASTHUGBID → DOPE → แผนการดูแล → สรุป · บันทึกอัตโนมัติ · "ส่งเวรต่อ" คัดลอกจากเวรก่อน |
| **สรุป** | ตรวจความครบถ้วน (บอกว่าขาดอะไร) · Draft → In Progress → Ready for Review → Handed Over (ล็อก) · บันทึกแก้ไขพร้อมเหตุผล · คัดลอกสรุป |
| **พิมพ์ A4** | แบบฟอร์มหน้าตาเหมือนกระดาษต้นฉบับ 1 หน้า A4 · พิมพ์ หรือ "บันทึกเป็น PDF" · มีแบบฟอร์มเปล่าใน ตั้งค่า |
| **ประวัติการส่งเวร** | วันนี้ / 7 วัน / 30 วัน / ทั้งหมด · ค้นหา · กรองสถานะ |
| **ตั้งค่า** | ชื่อผู้ใช้ (ใช้ใน Audit log) · หัวกระดาษ A4 · Export / Import · โหลดข้อมูลตัวอย่าง · Audit log · รายการที่ต้องให้ผู้เชี่ยวชาญตรวจ |

## ใช้บนคอม
ดับเบิลคลิก `index.html` (Edge / Chrome)

## ขึ้น GitHub Pages + ติดตั้งบนมือถือ
1. สร้าง repository ใหม่บน github.com (Public) แล้วกด **Add file → Upload files**
2. ลาก **ทุกไฟล์ในโฟลเดอร์นี้** (17 ไฟล์ ไม่มีโฟลเดอร์ย่อย) ไปวาง → Commit (ไฟล์ชื่อเดิมจะถูกแทนที่)
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch `main` / `/ (root)` → Save
4. รอ 1-2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`
* iPhone / iPad (Safari): ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
* Android (Chrome): เมนู ⋮ → **ติดตั้งแอป**

แก้ไฟล์แล้วอัปโหลดใหม่: เปลี่ยน `VERSION` ใน `sw.js` ด้วย (มือถือจะได้เวอร์ชันใหม่)

## ข้อมูล
* `localStorage` key `icuhandover.v1` = ผู้ป่วย, บันทึกส่งเวร, Audit log, ตั้งค่า (แต่ละเครื่องแยกกัน → Export / Import)
* ข้อมูลสมมติอยู่ใน `demo-data.js` (ทุกรายการมี `isDemo: true`)
* รายการ Checklist ทั้งหมดอยู่ใน `config.js` (แก้ข้อความได้โดยไม่ต้องแก้โค้ดส่วนอื่น)

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `config.js` | หัวข้อ / รายการในแบบฟอร์ม, สถานะ, รายการที่ต้องให้ผู้เชี่ยวชาญตรวจ |
| `store.js` | เก็บข้อมูล + Audit log (Phase 5 เปลี่ยนเป็นเรียก API ได้โดยคงชื่อฟังก์ชันเดิม) |
| `validate.js` | ตรวจความครบถ้วน + ข้อความสรุป |
| `editor.js` | หน้าบันทึกส่งเวร 5 ขั้น |
| `print.js` | แบบฟอร์ม A4 |
| `app.js` | เมนู, หน้าหลัก, ผู้ป่วย, ประวัติ, ตั้งค่า |
